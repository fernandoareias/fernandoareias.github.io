# Areias Technology

Site institucional estático da Areias Technology — consultoria em engenharia de sistemas distribuídos de alta disponibilidade e performance.

Publicado via GitHub Pages em [areiastech.com](https://areiastech.com).

## Stack

- HTML5 + CSS puro ([css/areias.css](css/areias.css))
- JavaScript vanilla, sem dependências ([js/main.js](js/main.js))

## Rodar localmente

```bash
python3 -m http.server
```

Acesse `http://localhost:8000`.
